Referer

If this page was in the Referer of a request to your website, it means a program created in the desktop app for the AmpMod programming language has successfully made a request to your site. AmpMod is a block-based programming language that introduces powerful capabilities for more advanced users.

We do not track users, so we cannot tell what project made the request or who created the project.

If you do not wish for AmpMod desktop projects to connect to your website, block requests containing AmpMod/ in their user agent. However, if a project on the web app makes a fetch, it usually refers to ampmod.codeberg.page, but sometimes it may be from a fork/mirror, as AmpMod is open-source and self-hostable software.

We only recommend doing this if a project is actively performing DoS attacks on your site, or if it contains sensitive information. The AmpMod developers are not responsible for fetches made by other users' projects.
