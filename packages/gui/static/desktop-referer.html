Referer

If this page was in the Referer of a request to your website, it means users are accessing your site using a program created in the desktop app for the AmpMod programming language.

Per our privacy policy, we do not track users, so we cannot tell what project made the request or who created the project.

If you do not wish for AmpMod desktop projects to make requests to your website, block requests containing AmpMod/ in their user agent. AmpMod projects running in the browser will remain unaffected.

We only recommend doing this if a project is actively performing denial-of-service attacks on your site, or if it contains sensitive information. The AmpMod developers are not responsible for fetches made by other users' projects.
